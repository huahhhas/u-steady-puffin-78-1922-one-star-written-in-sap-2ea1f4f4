A houseplant leaves a one-star review of its human owner — one line, under
280 characters, for the [make.fun](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
bounty "One Star, Written in Sap".

## The line

> ★☆☆☆☆ He bought me to "purify the air", then keeps me in a windowless bathroom next to the air freshener. I have one job and he gave it to a plug-in. One star.

## Run it

```sh
python3 main.py
```

`main.py` prints exactly that one line; `entry.txt` holds the same output.
